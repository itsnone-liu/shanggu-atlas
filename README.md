# 上古图谱 shanggu-atlas

中国上古文明演化知识图谱：从现代人进入东亚（~5万年前）到周灭商（前1046年），
以**自然物质原因**（气候事件、环境变迁、生业技术）为驱动骨架，
考古学文化为血肉，分子人类学为主线证据，神话传说为投影层。

## 方法论（三原则）

1. **自然驱动筛选器**：优先收录"事件=自然原因→人群响应"的因果链
   （如 仙女木冷事件→农业起源压力；4.2ka 干旱→龙山期转型与洪水记忆）。
2. **置信度分层**：每条实体与关系必须标注 A-E 级，网页可按级过滤：
   - A 实证（发掘报告、直接测年、古DNA序列）
   - B 学界主流（多数派假说）
   - C 竞争假说（有论文支持，未定）
   - D 推测（个别学者/合理推断，含自然主义神话解读）
   - E 传说（纯文献记载，只作对照投影）
3. **假说可以激进，但必须打标签**：例如"炎黄三次战争=南方稻作文化趁
   气候波动向北扩张引发的集团冲突记忆"——收编为 D 级关系，不冒充史实。

## 七幕框架

1. 深古 (~50k-12k BP)：南北两条线进入东亚、N/O 支系分化、末次盛冰期、仙女木事件
2. 农业起源 (12k-8k)：稻粟驯化、高庙祭祀传统
3. 文化爆发 (8k-6k)：兴隆洼-红山、裴李岗-仰韶、8.2ka 冷事件
4. 仰韶-庙底沟扩张 (6k-5k)：彩陶文化圈≈早期华夏雏形；炎黄神话投影层
5. 龙山万邦 (4.5k-3.7k)：4.2ka 大干旱→洪水记忆/大禹治水
6. 二里头-早商 (3.8k-3.3k)：青铜王权
7. 殷商-牧野 (3.3k-3.0k)：甲骨文信史 → 前1046 灭商（终点）
